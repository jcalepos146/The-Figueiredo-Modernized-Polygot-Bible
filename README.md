# The Figueiredo Polyglot — Complete New Testament

A GitHub Pages-ready trilingual New Testament reader with the Clementine Vulgate, a historical Spanish public-domain text, the Douay-Rheims tradition, chapter arguments, and annotations associated with António Pereira de Figueiredo.

## Quality-of-life features

- Full-text search across Scripture, arguments, and annotations
- Direct chapter, verse, and annotation URLs
- Copy, citation, share, and local bookmark tools for each verse
- Latin/Spanish/English display combinations
- Collapsible grouped navigation and keyboard shortcuts
- Continue Reading and recent-history cards
- Parchment, light, and dark themes; font, spacing, and width controls
- Annotation popovers with verse backlinks and provenance labels
- Print-friendly formatting and an installable PWA shell
- Local offline storage for Tomo VI Scripture columns after first download
- Accessibility improvements: semantic controls, language tags, focus states, and reduced-motion support

## Publish on GitHub Pages

1. Upload the contents of this folder to the repository root.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select `main` and `/root`.

No build step is required.

## Routes

- Chapter: `#john-6`
- Verse: `#john-6-v53`
- Annotation: `#john-6-note-a`

## Offline note

Matthew through Hebrews are embedded in `index.html`. James through Revelation download their public-domain Scripture columns on first use and store them locally. The **Make Tomo VI available offline** command downloads all eight remaining books in one operation while connected.
